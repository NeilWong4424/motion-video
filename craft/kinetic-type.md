# Kinetic Type

## Purpose / Use when

Use for typography-led films, labels, captions, headlines, and any text that changes during a bridge.

## Reads

Read approved copy and facts, resolved font constraints, copy strategy, motion profile, `motion-craft.md`, and `continuity-first.md`.

## Writes

None. This module performs no artifact writes.

## Must

- Preserve reading order, hierarchy, safe areas, and a settled hold for consequential copy.
- Assign stable identity to persisting text and use a declared crossfade, masked reveal, shared-text morph, or replace-on-action for content changes.
- Choreograph emphasis around meaning: reveal a word, relation, or conclusion only when it improves comprehension.
- Use profile-bound starting ranges for entry, settle, and hold; adjust them for copy density, language, format, and accessibility.
- Validate that line breaks, glyph coverage, and contrast are resolved before treating type as motion material.

## Must not

- Pop text on a single bridge frame, animate every glyph by default, or turn type into decorative noise.
- Use an unresolved or unlicensed font, distort a claim through timing, or make a readable hold vanish for pace.

## Stop conditions

Stop when copy is unverified, overflows, has missing glyphs, fails safe-area or contrast needs, or no truthful content transition is available.

## Output schema

None.

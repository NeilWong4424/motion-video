# Style System

## Purpose / Use when

Use to turn the Treatment's visual thesis into a limited, coherent system of contrast, typography, shape language, spacing, texture, and transition behavior.

## Reads

Read the Brief constraints, approved Treatment, supplied local assets and fonts, and the relevant domain craft module.

## Writes

None. This module performs no artifact writes.

## Must

- Define a small set of repeated visual decisions so every Beat belongs to the same film, even when content changes.
- Protect message hierarchy with contrast, scale, whitespace, and accessible legibility before ornament.
- Carry continuity through recurring anchors, shape language, and restrained transition vocabulary without copying whole frames.
- Match motion character to the approved motion profile; profile-bound ranges are starting points, not universal rules.
- Use only supplied, locally licensed assets and resolved fonts.

## Must not

- Use a style pack to override facts, accessibility, local-asset constraints, or seamless-default.
- Drift into unrelated palettes, type systems, shadows, textures, or motion personalities between Beats.
- Add visual noise merely to make a held shot feel busy.

## Stop conditions

Stop when the system conflicts with brand constraints, creates unreadable content, lacks licensed sources, or cannot represent verified facts truthfully.

## Output schema

None.
